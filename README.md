# Rynix

A statically-typed, diagnostics-first programming language with a
hand-written compiler, written in Rust.

Rynix is designed to be a language you can write real algorithms in — up
to DSA level — with best-in-class error messages and time/space
complexity treated as a first-class concern.

**Status:** early development (v0.1 — lexer).
See [`docs/DESIGN.md`](docs/DESIGN.md) for the language design.

## Build & run

```bash
cargo run
```
